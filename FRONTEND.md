# Обработка расшифровки во фронтенде

Откройте `index.html` через Live Server или существующий сервер проекта.
Интерфейс загружает только локальные HTML/CSS/JS-файлы. Для анализа текста
backend, ключи API и интернет не нужны.

1. Вставьте расшифровку с именами перед репликами или нажмите «Пример встречи».
2. Нажмите «Обработать текст».
3. Проверьте ключевые вопросы, разделённые реплики и вкладку «Поручения».
4. В карточке поручения раскройте исходную цитату. Уточните ответственного
   и срок, затем нажмите «Подтвердить поручение».

Исходный текст не заменяется результатом. Результат и правки хранятся только
в памяти открытой страницы; перезагрузка их сбрасывает.

## Метод и ограничения

`transcript-analyzer.js` — детерминированный разбор по языковым правилам,
а не языковая модель. Он распознаёт текстовые метки говорящих, ряд русских
и казахских формулировок действий и сроков, отбирает содержательные
предложения с показателями и проблемами. Неоднозначные назначения
помечаются для проверки; отсутствующие сроки не выдумываются.

Имена определяются по тексту, голосовая диаризация не выполняется. Выбор файла
и запись микрофона дают локальную аудиозапись для скачивания. Автоматическое
распознавание аудио на этом экране не подключено: для текстового анализа
нужно вставить расшифровку. Запись работает при разрешении микрофона на HTTPS
или localhost.

Текущий серверный экспорт формирует фиксированный демонстрационный протокол.
Интерфейс сообщает об этом и не скачивает его как результат новой обработки.
Backend и его API этой доработкой не изменяются.

## Проверка

```sh
node --test tests/test-transcript-analyzer.cjs
node --check app.js
```

Тесты проверяют извлечение разных поручений, указанные и неизвестные сроки,
имена и обращения, отрицания, смешанную речь, исходные цитаты и повторный
анализ одного текста.
